# Gizy 🍎

**Gizy** adalah website edukasi gizi yang dibuat untuk membantu keluarga memahami pola hidup sehat dengan cara yang sederhana dan mudah dipraktikkan.

Di dalamnya tersedia kalkulator BMI, artikel seputar gizi, serta chatbot yang bisa digunakan untuk mencari informasi tentang pola hidup sehat.

---

## 🖥️ Cara Membuka Website

### Cara 1 — Online

Buka link demo berikut melalui browser:

👉 **[Link Demo Website](https://gizyedu.vercel.app)**

### Cara 2 — Dari File Project

Kalau ingin menjalankannya langsung dari project:

1. Download dan extract folder project.
2. Buka file `index.html`.
3. Jalankan dengan browser.

Website tidak membutuhkan instalasi tambahan. Namun, penggunaan **Live Server di VS Code** disarankan agar video intro dapat berjalan dengan lebih baik.

## 📖 Bagian-Bagian Website

| Halaman            | Isi                                                                                | Cara Mengakses   |
| ------------------ | ---------------------------------------------------------------------------------- | ---------------- |
| **Home**           | Informasi masalah gizi anak, panduan piring sehat, tips makan, dan preview artikel | Halaman pertama  |
| **BMI Kalkulator** | Perhitungan BMI, kebutuhan kalori, dan saran gizi                                  | Klik **BMI**     |
| **Blog**           | Artikel gizi, pencarian, dan pagination                                            | Klik **Blog**    |
| **ChatBot**        | Tanya jawab seputar pola hidup sehat                                               | Klik **ChatBot** |

### Fitur yang Bisa Dicoba

* **BMI Kalkulator** — masukkan jenis kelamin, umur, tinggi, dan berat badan untuk melihat hasil BMI beserta informasi tambahannya.
* **Kartu Tips Makan Sehat** — arahkan mouse atau tap kartu untuk melihat sisi belakang yang berisi tips.
* **ChatBot** — pilih topik yang tersedia atau tulis pertanyaan sendiri, kemudian lihat respons bot dengan animasi.
* **Statistik Stunting** — arahkan mouse ke bagian statistik untuk melihat angka yang ditampilkan secara animatif.

## ✅ Hal yang Bisa Diperhatikan

Website dirancang agar tetap nyaman digunakan pada berbagai ukuran layar, mulai dari desktop hingga mobile 320px.

Beberapa interaksi yang bisa diperhatikan antara lain:

* Navbar berubah ketika halaman di-scroll.
* Menu mobile memiliki animasi.
* Video intro muncul ketika website pertama kali dibuka.
* Kartu, tombol, dan gambar memiliki efek interaksi.
* Pencarian artikel pada halaman Blog dapat digunakan.
